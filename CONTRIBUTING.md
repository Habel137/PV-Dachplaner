# Mitmachen

Danke, dass du den PV-Dachplaner verbessern möchtest!

1. Erstelle bei größeren Änderungen zuerst ein Issue und beschreibe den Vorschlag.
2. Forke das Repository und arbeite in einem eigenen Branch.
3. Halte Änderungen möglichst klein und nachvollziehbar.
4. Teste die Anwendung lokal in einem aktuellen Browser.
5. Erstelle einen Pull Request mit einer kurzen Beschreibung und einer Liste der durchgeführten Tests.

Bitte keine privaten Dachbilder, Adressen oder persönlichen Projektdateien in Commits, Issues oder Pull Requests veröffentlichen.
