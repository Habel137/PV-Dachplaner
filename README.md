# PV-Dachplaner

Ein kostenloser, browserbasierter Planer für eine erste, manuelle Photovoltaik-Belegung von Dachflächen.

Der PV-Dachplaner ist ein Community-Projekt. Du kannst ihn verwenden, untersuchen, verändern und verbessern. Beiträge, Fehlerberichte und neue Ideen sind willkommen.

## Funktionen

- Eigenes Hintergrund-/Luftbild im Browser laden
- Maßstab anhand einer bekannten Strecke kalibrieren
- Dachflächen als Polygone einzeichnen und bearbeiten
- Dachneigung und Azimut je Dachfläche festlegen
- PV-Module platzieren, verschieben, drehen, duplizieren und löschen
- Projekte lokal als JSON speichern und wieder laden
- Keine Registrierung und kein Serverkonto erforderlich

## Schnellstart

1. `index.html` herunterladen.
2. Die Datei in einem aktuellen Browser öffnen.
3. Ein eigenes Dachbild laden und den Maßstab kalibrieren.
4. Dachflächen einzeichnen und Module planen.
5. Das Projekt bei Bedarf als JSON-Datei speichern.

Alternativ kann das Repository über GitHub Pages veröffentlicht werden: In GitHub unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/ (root)` auswählen.

## Mitmachen

Beiträge sind willkommen! Du kannst:

- einen Fehler über **Issues** melden,
- eine Idee oder Verbesserung vorschlagen,
- das Repository forken und Änderungen per **Pull Request** einreichen.

Bitte beschreibe bei Fehlerberichten möglichst genau, wie der Fehler reproduziert werden kann. Verwende für Screenshots und Beispieldateien nur Dachbilder und Projektdaten, die du veröffentlichen darfst. Private Adressen und persönliche Bilder bitte vorher entfernen.

## Wichtige Hinweise

Der PV-Dachplaner ist ein Werkzeug zur unverbindlichen Vorplanung. Ergebnisse hängen unter anderem von Bildqualität, Maßstab, Dachgeometrie und den eingegebenen Daten ab. Eine Darstellung oder Modulanzahl ist keine Zusicherung, dass eine Anlage tatsächlich montiert werden kann.

Vor einer Installation müssen Maße vor Ort geprüft und insbesondere Statik, Dachzustand, Brandschutz, Abstände, Wind-/Schneelasten, elektrische Auslegung, Wechselrichterauslegung und geltende Vorschriften durch qualifizierte Fachleute beurteilt werden. Der Planer ersetzt keine Fachplanung und keine Prüfung vor Ort.
