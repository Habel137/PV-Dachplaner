# PV-Dachplaner

Ein kostenloser, browserbasierter Planer zur Erstellung einer eigenen Photovoltaik-Belegung.

Mit dem PV-Dachplaner können Dachflächen anhand eines eigenen Luftbildes eingezeichnet und mit Solarmodulen belegt werden. Dachneigung und Ausrichtung lassen sich für jede Dachfläche individuell einstellen.

Der Planer besteht aus einer einzelnen HTML-Datei und kann ohne Installation direkt im Browser verwendet werden.

## Funktionen

- Eigenes Dachbild hochladen
- Bildmaßstab kalibrieren
- Dachflächen einzeichnen und bearbeiten
- Dachneigung und Azimut festlegen
- PV-Module platzieren, verschieben und drehen
- Modulanzahl und Gesamtleistung anzeigen
- Projekte speichern und laden

## Verwendung

1. `index.html` herunterladen.
2. Datei im Browser öffnen.
3. Eigenes Dachbild hochladen.
4. Maßstab einstellen und Dachflächen einzeichnen.
5. Module platzieren und Planung speichern.

Keine Installation, Registrierung oder Internetverbindung erforderlich.

## Mitmachen

Das Projekt ist Open Source und steht unter der MIT-Lizenz.

Verbesserungen, neue Funktionen und Fehlerberichte sind willkommen. Das Repository kann geforkt und durch Pull Requests erweitert werden.

## Hinweis

Der PV-Dachplaner dient der unverbindlichen Vorplanung. Die tatsächlichen Maße, Montagebedingungen, Statik und elektrische Auslegung müssen vor einer Installation fachgerecht geprüft werden.
