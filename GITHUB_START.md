# GitHub-Veröffentlichung – Kurz-Anleitung

1. Auf https://github.com einloggen oder kostenlos registrieren.
2. Über **New repository** ein neues Repository erstellen.
3. Name z. B. `pv-dachplaner`; Sichtbarkeit **Public** auswählen.
4. Die Dateien aus diesem Paket hochladen (nicht den ZIP-Ordner selbst).
5. Commit changes bestätigen.
6. Optional: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
7. Nach dem Deployment zeigt GitHub Pages eine öffentliche URL an.

## Zusammenarbeit
Andere können das öffentliche Repository ansehen und forken. Sie können Änderungen als Pull Request vorschlagen. Du entscheidest, welche Änderungen übernommen werden. Gib Schreibrechte nur Personen, denen du vertraust.

## Lizenz
Die MIT-Lizenz ist eine sehr freie Open-Source-Lizenz: Andere dürfen den Code auch kommerziell nutzen und verändern, müssen aber den Lizenz- und Copyright-Hinweis beibehalten. Die Lizenz ist keine Garantie für technische Eignung oder Sicherheit.
